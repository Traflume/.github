## О проекте

**Traflume** — платформа для покупки и продажи Telegram-трафика, размещения заданий и подключения рекламных интеграций к ботам. Сервис объединяет создание заказов, проверку ресурсов, выдачу заданий пользователям, подтверждение выполнения и учёт операций.

Заказчики используют Traflume для продвижения своих Telegram-ресурсов. Владельцы ботов подключают задания и монетизируют взаимодействие с аудиторией. Разработчики встраивают получение и проверку заданий в собственные продукты через API.

С платформой можно работать через сайт, личный кабинет и Telegram-бот. Для управления заказами предусмотрена CRM, а для интеграций — документация, SDK и готовые примеры.

| Кому | Что даёт Traflume |
| --- | --- |

## Возможности платформы

### Заказы и продвижение

Создавайте заказ по ссылке на ресурс, задавайте объём, стоимость и доступные параметры аудитории. Черновик позволяет подготовить заказ и проверить настройки перед отправкой на модерацию.

В карточке заказа доступны его состояние, параметры и результаты. После одобрения можно управлять размещением, приостанавливать заказ и возобновлять его работу.

### Ресурсы и интеграции

Добавляйте ботов, каналы, чаты и другие поддерживаемые ресурсы. У каждого ресурса есть карточка и статус проверки. Подключение включает подтверждение владения или необходимых прав доступа.

Для ботов предусмотрены отдельные интеграции и API-ключи. Задания можно встроить в существующую логику: например, предложить пользователю выполнить действия перед получением файла, материала или доступа к функции.

### Личный кабинет и CRM

Кабинет собирает заказы, подключённые ресурсы, статистику, баланс и настройки аккаунта. CRM дополняет управление заказами заметками, тегами и этапами работы.

История событий помогает проследить изменения заказа, а история финансовых операций — разобраться в начислениях, списаниях и зарезервированных суммах.

### Telegram-бот и Mini App

Telegram-бот даёт доступ к основным действиям сервиса: работе с заказами и ресурсами, кабинету, балансу, настройкам и поддержке. Mini App используется для сценариев, которым нужен веб-интерфейс внутри Telegram.

### Баланс и поддержка

В аккаунте доступны баланс, история операций и обращения по пополнению или выводу средств. Условия и итоговые суммы отображаются в соответствующих финансовых сценариях.

Вопросы по работе сервиса можно решать через поддержку, сохраняя историю обращения и ответов.

## Как устроена работа

### Для заказчика

1. Добавьте Telegram-ресурс и подготовьте заказ.
2. Настройте параметры размещения и пройдите необходимые проверки.
3. Отправьте заказ на модерацию.
4. Управляйте одобренным заказом и следите за результатами в кабинете или боте.

### Для владельца бота

1. Подключите своего бота в кабинете и настройте интеграцию.
2. Получайте подходящие задания через API.
3. Показывайте пользователю действия и ссылки из ответа сервиса.
4. Проверяйте выполнение и связывайте подтверждённый результат с логикой своего бота.

Например, бот может выдавать учебный материал после выполнения предложенных заданий. Интеграция сохраняет выданный набор, проверяет его выполнение и открывает доступ по подтверждённому ответу Traflume.

## Разработчикам

Публичный REST API охватывает работу с заказами, отчётами и заданиями. Спецификация OpenAPI описывает маршруты, поля, права доступа и формат ошибок.

Для интеграции заданий предусмотрены получение предложений и последующая проверка выполнения. Ответ API содержит признак `can_proceed`, по которому бот определяет, можно ли выдать пользователю обещанный материал или доступ.

Доступны:

- **Python SDK** — клиент для обращения к API, включая асинхронные вызовы.
- **JavaScript-клиент** — пример работы с сервисом из Node.js.
- **Пример на aiogram** — получение заданий, кнопки, проверка, сохранение состояния и выдача файла.
- **Инструкция для редактора с ИИ** — описание полного цикла интеграции в существующий проект.

Параметры авторизации, ограничения запросов и правила повторной обработки описаны в документации. Ключи интеграции и токен бота хранятся на сервере.
