<h1 align="center">Traflume</h1>

<p align="center">Трафик, задания и интеграции для Telegram.</p>

---

Traflume — платформа для работы с Telegram-трафиком. Сайт, личный кабинет, CRM, API и Telegram-бот объединяют заказы, задания и интеграции в одном сервисе.

- **Заказчикам** — создание заказов, управление продвижением и работа с результатами.
- **Владельцам ботов** — подключение заданий и проверка их выполнения.
- **Разработчикам** — REST API, спецификация OpenAPI и примеры интеграции на Python и Node.js.

Начните с [документации по интеграции](https://traflume.org/docs/integration-llm.md).
